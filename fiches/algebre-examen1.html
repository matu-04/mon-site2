A2Opérations — les propriétés pièges Tema 1, Teorema 11

⭐ À retenir absolument
Le cours insiste dessus (Tema 1, p. 2).
  1. A·B ≠ B·A en général. Le produit matriciel n'est pas commutatif.
  2. A·B = Θ n'implique pas A = Θ ou B = Θ. Donc A·B = A·C n'implique pas B = C (pas de simplification).
  3. A·(B+C) = A·B + A·C — distributivité : vraie.
  4. (A·B)·C = A·(B·C) — associativité : vraie.
  5. A·Iₙ = Iₘ·A = A.
⚠ Conséquence directe — exercice 5 de l'EPD Tema 1
(A+B)² ≠ A² + 2AB + B² en général, car (A+B)² = A² + AB + BA + B² et AB ≠ BA.
Idem : (A+B)(A−B) ≠ A² − B².

Transposée (Teorema 15)

  • (Aᵗ)ᵗ = A
  • (A+B)ᵗ = Aᵗ + Bᵗ
  • (λA)ᵗ = λAᵗ
  • (A·B)ᵗ = Bᵗ·Aᵗ  ← l'ordre s'inverse
📐 Dimensions
A(m×n) · B(n×l) → (m×l). Colonnes de A = lignes de B, sinon l'opération est impossible.
En examen, « calcular cuando sea posible » signifie qu'il y a des pièges de dimension dans le lot.

A5Matriz inversa Tema 1, §6

Teorema 27 — le théorème clé
A est inversible si et seulement si det(A) ≠ 0. Dans ce cas :

A⁻¹ = (1 / det A) · adj(A)ᵗ

Propriétés (Teorema 24)

  • (A⁻¹)⁻¹ = A
  • (A·B)⁻¹ = B⁻¹·A⁻¹  ← l'ordre s'inverse
  • (Aᵗ)⁻¹ = (A⁻¹)ᵗ

Teorema de Rouché-Fröbenius (Tema 2, Teorema 7) — LE théorème de l'examen

Rouché-Fröbenius
Le système A·x = b admet une solution si et seulement si rg(A) = rg(A|b). Dans ce cas :
  • si rg(A) = n (nombre d'inconnues) → S.C.D. (solution unique)
  • si rg(A) < n → S.C.I., avec n − rg(A) grados de libertad

Schéma de décision à appliquer mécaniquement :

rg(A) ≠ rg(A|b)→S.I.
rg(A) = rg(A|b) = n→S.C.D.
rg(A) = rg(A|b) < n  (n − rg(A) degrés de liberté)→S.C.I.

Método de Gauss (Tema 2, §3)

Transformaciones elementales — elles conservent les solutions (sistemas equivalentes) :

NotationOpération
Fᵢⱼéchanger les lignes i et j
Fᵢ(α)multiplier la ligne i par α ≠ 0
Fᵢⱼ(α)ajouter à la ligne i la ligne j multipliée par α

Sistema escalonado : sous la diagonale tout est nul, chaque pivot est à droite du pivot de la ligne précédente, les lignes nulles sont en bas. Puis sustitución regresiva (remontée) : on résout de la dernière équation vers la première.

🔎 Lecture du système échelonné
  • une ligne 0 0 0 | b avec b ≠ 0 → S.I.
  • nombre de pivots = nombre d'inconnues → S.C.D.
  • nombre de pivots < nombre d'inconnues → S.C.I. ; les inconnues sans pivot sont les incógnitas libres, on leur donne un paramètre (λ, t…)
Incógnitas básicas = colonnes avec pivot · Incógnitas libres = colonnes sans pivot.

TYPE 1Calculs matriciels « calcular cuando sea posible »

ClearAll[a, b, c]
a = {{1, 1, 2, 1}, {0, 1, 1, 1}, {2, 0, 2, 2}};
b = {{1, -3, 2}, {2, 0, 2}, {4, -3, -1}};

MatrixForm[a]                (* vérifier qu'on a bien saisi *)
Dimensions[a]                (* {3, 4} : 3 lignes, 4 colonnes *)
MatrixForm[b.b.b]            (* B^3 *)
MatrixForm[Transpose[a].b]   (* A^t · B *)
MatrixRank[a]
Det[b]
MatrixForm[Inverse[b]]
✅ Réflexe avant chaque produit
Vérifier avec Dimensions que colonnes de la 1ʳᵉ = lignes de la 2ᵉ. Une erreur rouge Dot::dotsh, c'est exactement ça. Si l'opération est impossible, écris-le et justifie par les dimensions — c'est une réponse attendue, pas un échec.
⚠ Avant Inverse[a], calcule Det[a]
Si det = 0, la matrice n'est pas inversible : tu dois le dire au lieu de laisser Mathematica renvoyer une erreur.

ClearAll[a, ab]
(* 1. matrice des coefficients *)
a = {{1, 1, 1}, {0, 3, -1}, {0, 0, 1}};
(* 2. matrice ampliada : on ajoute la colonne des termes indépendants *)
ab = {{1, 1, 1, 2}, {0, 3, -1, 3}, {0, 0, 1, 6}};

MatrixRank[a]    (* rg(A)    *)
MatrixRank[ab]   (* rg(A|b)  *)
(* 3. appliquer Rouché-Fröbenius à la main, puis : *)
Solve[{x + y + z == 2, 3 y - z == 3, z == 6}, {x, y, z}]
✍ La rédaction attendue (le calcul seul ne suffit pas)
rg(A) = 3, rg(A|b) = 3, n = 3 inconnues.
Comme rg(A) = rg(A|b) = n, par le teorema de Rouché-Fröbenius le système est compatible determinado.
Solution : x = …, y = …, z = …
Si S.C.I., ajoute : « con n − rg(A) = … grados de libertad, la solución viene expresada en función de … »

TYPE 3Discuter un système avec paramètre LE PLUS PROBABLE

Le modèle de la Práctica 2 — le PDF le détaille entièrement (Práctica 2, p. 2–3). Quatre étapes, toujours les mêmes :

Étape 1Matrice des coefficients avec le paramètre
Étape 2Valeurs critiques : Solve[Det[a]==0]
Étape 3Cas général (det ≠ 0) → S.C.D.
Étape 4Chaque valeur critique, une par une → S.I. ou S.C.I.
ClearAll[a, m, x, y, z]

(* ÉTAPE 1 — matrice des coefficients avec le paramètre *)
a = {{1, 1, 2}, {-1, m, 2}, {3, 0, m}};

(* ÉTAPE 2 — valeurs critiques : celles qui annulent le déterminant *)
Solve[Det[a] == 0]
(* → {{m -> 2}, {m -> 3}} *)

(* ÉTAPE 3 — cas général : m ≠ 2 et m ≠ 3 *)
ClearAll[m]
Solve[{x + y + 2 z == 2, -x + m*y + 2 z == 0, 3 x + m*z == 4}, {x, y, z}]
(* det ≠ 0 → rg(A) = rg(A|b) = 3 = n → S.C.D., solution unique en fonction de m *)

(* ÉTAPE 4 — chaque valeur critique, une par une *)
m = 2;
Solve[{x + y + 2 z == 2, -x + m*y + 2 z == 0, 3 x + m*z == 4}, {x, y}]
(* → solution en fonction de z : S.C.I. *)

ClearAll[m]
m = 3;
Solve[{x + y + 2 z == 2, -x + m*y + 2 z == 0, 3 x + m*z == 4}, {x, y, z}]
(* → {} : S.I. *)

ClearAll[m]   (* NE JAMAIS OUBLIER *)
🧠 Le raisonnement mathématique derrière (c'est ce qui est noté)
  • det(A) ≠ 0 ⟺ rg(A) = n ⟺ S.C.D. Donc seules les valeurs qui annulent le déterminant posent problème.
  • Pour chaque valeur critique, le rang chute : comparer rg(A) et rg(A|b) pour cette valeur afin de trancher entre S.I. et S.C.I.
☠ Piège mortel — signalé explicitement par le PDF
m = 2 assigne la valeur globalement. Tant que tu n'as pas fait ClearAll[m], tous les calculs suivants utilisent m = 2 — et tes résultats sont faux sans aucun message d'erreur.
💡 Complément (hors cours)
La substitution temporaire expr /. m -> 2 donne le même résultat sans assigner m, donc sans ce piège. Mais écris quand même ClearAll[m] dans ta copie : c'est la méthode du cours, et le prof la cherche.
D

Les 10 erreurs qui coûtent des points

À relire juste avant l'examen
  1. a*b au lieu de a.b pour un produit matriciel.
  2. Un seul = dans Solve au lieu de ==.
  3. Oublier ClearAll[m] entre deux valeurs du paramètre.
  4. Calculer Inverse[a] sans avoir vérifié Det[a] ≠ 0.
  5. Confondre matriz de coeficientes A et matriz ampliada (A|b) pour les rangs.
  6. Donner le résultat Wolfram sans conclure en vocabulaire du cours (S.C.D. / S.C.I. / S.I.).
  7. Oublier de préciser les grados de libertad dans un S.C.I.
  8. Écrire det[a] ou solve[...] en minuscule.
  9. Réutiliser une variable définie plus haut sans l'effacer (vaut pour x, a, m…).
  10. Multiplier des matrices dont les dimensions ne concordent pas, au lieu de répondre « no es posible » avec justification.

Auto-test

Réponds de tête avant d'ouvrir la réponse
1rg(A) = 2, rg(A|b) = 3, 3 inconnues. Quel type de système ? Pourquoi ?
S.I. — rg(A) ≠ rg(A|b), donc par Rouché-Fröbenius le système n'a pas de solution.
2rg(A) = rg(A|b) = 2, 4 inconnues. Type de système et degrés de liberté ?
S.C.I. avec n − rg(A) = 4 − 2 = 2 grados de libertad.
3Un système homogène peut-il être incompatible ? Justifie.
Non. Il admet toujours la solución trivial (0, …, 0) ; ajouter une colonne de zéros ne change pas le rang, donc rg(A) = rg(A|b).
4Commande Wolfram qui donne les valeurs de m annulant le déterminant de a ?
Solve[Det[a] == 0] (ou Solve[Det[a] == 0, m]).
5Quelle est la différence entre a*b et a.b ?
a*b = produit terme à terme ; a.b = produit matriciel (le seul correct pour A·B).
6(A·B)ᵗ = ?  Et (A·B)⁻¹ = ?
(A·B)ᵗ = Bᵗ·Aᵗ  et  (A·B)⁻¹ = B⁻¹·A⁻¹ — l'ordre s'inverse dans les deux cas.
7Que signifie une sortie {} de Solve ?
Aucune solution → système incompatible (S.I.).
8Pourquoi écrire ClearAll[m] après avoir testé m = 3 ?
Parce que m = 3 est une assignation globale : sans ClearAll[m], tous les calculs suivants utilisent m = 3 et donnent des résultats faux sans message d'erreur.
9Traduis : matriz ampliada, grados de libertad, sustitución regresiva.
Matrice augmentée · degrés de liberté · substitution ascendante (remontée).
10A est 3×4, B est 4×2. A·B est-il possible ? De quelle dimension ? Et B·A ?
A·B : oui (4 = 4) → matrice 3×2.  B·A : (4×2)·(3×4) → 2 ≠ 3, impossible (« no es posible »).
